# nocturna · estudio creativo — Wordmark

Tipografía elegida: **Unbounded Bold (700)** para "nocturna".
Subtítulo "estudio creativo" en **Space Grotesk Regular (400)**, gris, con tracking amplio.

## Archivos
- `nocturna-wordmark-oscuro.svg` — para fondos oscuros (texto blanco)
- `nocturna-wordmark-claro.svg` — para fondos claros (texto negro)
- `nocturna-wordmark-codigo.html` — snippet HTML + CSS listo para pegar
- `nocturna-wordmark-react.jsx` — componente React/JSX

## Colores
- nombre: #FFFFFF (oscuro) / #0A0A0A (claro)
- subtítulo: #555555 (oscuro) / #888888 (claro)

## Fuentes (Google Fonts)
- Unbounded weight 700  → el nombre
- Space Grotesk weight 400 → el subtítulo

## Recomendación de uso
- Centrado para hero / piezas. Alineado a la izquierda para el header del sitio.
- La relación de tamaño nombre:subtítulo es aprox. 3.3:1. Mantené esa proporción al escalar.
- Más adelante, cuando sumes el isotipo (el ojo ámbar), puede ir arriba o a la izquierda del wordmark.

## Nota
Los SVG usan texto real con @import de la fuente. Si necesitás un SVG 100% portable
(que se vea igual sin la fuente instalada), hay que convertir el texto a contornos (outlines)
en Figma/Illustrator: seleccionar texto → "Outline / Convertir a trazado". Decime si lo necesitás así.
